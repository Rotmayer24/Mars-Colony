# Mars Colony - Survival Game

Минималистичная игра на выживание, вдохновлённая Frostpunk, действие которой происходит на Марсе.

## Требования

- Python 3.12+
- Pygame 2.6+

## Установка

```bash
uv sync
```
```bash
или
pip install pygame
```

## Запуск

```bash
uv run main.py
```
или
```bash
python main.py
```

## Управление

### Камера
- **Колесо мыши** - Приближение/отдаление (zoom 0.5x - 2.0x)
- **WASD** или **Стрелки** - Перемещение камеры по карте
- Камера позволяет детально рассмотреть колонию или увидеть всю картину целиком

### Клавиши строительства
- **1** - Генератор энергии (30 ресурсов)
- **2** - Система жизнеобеспечения (40 ресурсов)
- **3** - Теплица (35 ресурсов)
- **4** - Обогреватель (15 ресурсов)
- **5** - Жилой модуль (50 ресурсов)
- **6** - Ремонтный дрон (60 ресурсов, требует исследование)
- **7** - Аккумулятор (40 ресурсов, требует исследование)

### Игровые действия
- **ЛКМ** - Выбрать здание / Построить (в режиме строительства)
- **ПКМ** - Ремонт здания (10 ресурсов)
- **R** - Открыть панель исследований
- **Пробел** - Замедлить время (0.5x)
- **ESC** - В Меню

## Игровые системы

### Ресурсы
- **Энергия** - Производится генераторами, потребляется всеми зданиями
- **Кислород** - Производится системами жизнеобеспечения, потребляется колонистами
- **Ресурсы** - Производятся теплицами, используются для строительства и ремонта

### Тепло
Обогреватели греют соседние клетки. Теплицы работают только в тепле.

### События
Каждые 3-4 минуты происходит кризис:
- **Пыльная буря** - Все здания получают двойной урон
- **Утечка кислорода** - Система жизнеобеспечения начинает течь
- **Поломка оборудования** - Случайное здание получает серьёзный урон

### Исследования
8 исследований в 4 уровнях:
- Tier 1: Эффективные панели, Улучшенная изоляция
- Tier 2: Продвинутая система жизнеобеспечения, Автоматический ремонт
- Tier 3: Гидропоника, Резервное питание
- Tier 4: Оптимизация колонии, Укреплённые модули

## Цель игры

Выжить как можно дольше. Игра заканчивается когда:
- Все колонисты погибли
- Все системы жизнеобеспечения уничтожены

## Структура проекта

## Особенности

- Только геометрическая графика (прямоугольники, круги, линии)
- Никаких текстур или спрайтов
- Простая, но глубокая механика выживания
- Система исследований с деревом технологий
